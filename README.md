# Etiquetas O.S. — TedTech

Sistema web para impressão de etiquetas de Ordem de Serviço na impressora térmica **XP-1271U** (etiqueta Pimaco TR6030, 60×30mm).

- Logo TedTech e telefone fixos em toda impressão
- Nº da O.S. e data de entrada centralizados (número avança sozinho a cada impressão)
- Tudo em preto de alto contraste (ideal para impressão térmica)
- Tamanho do rótulo, telefone, logo e escala do texto ajustáveis nas Configurações
- Configurações salvas no próprio navegador (nada é enviado para fora)

## Como usar

É uma página única (`index.html`). Abra no navegador, preencha o Nº da O.S. e a data, e clique em **Imprimir etiqueta**. Na janela de impressão escolha a **XP-1271U**, margens **Nenhuma** e papel **60×30mm**.

## Publicar no GitHub Pages

1. Crie um repositório e envie o `index.html` (e este README).
2. Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`.
3. O link fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
